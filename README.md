# Лабораторна робота №3. Проєктування REST API

Метою роботи є розробити REST API веб-сервіс для керування каталогом товарів із підтримкою HTTP Basic аутентифікації та тестуванням через Postman.

Було реалізовано HTTP Basic аутентифікацію. Дані користувачів (логін і пароль) зберігаються у словнику всередині програми. Для доступу до API необхідно передати заголовок Authorization. Перевірка облікових даних виконується перед обробкою кожного запиту.

Рисунок 1 - Аутенфікація користувача

Для перегляду всіх товарів використовується метод GET за ендпоінтом /items. У відповідь сервер повертає список товарів у форматі JSON.


<img width="914" height="808" alt="{95F9425C-DAAF-4538-9C5A-8BCB87831519}" src="https://github.com/user-attachments/assets/5b58450a-1897-4e15-9fee-38e61bf361f6" />

Рисунок 2 - Перегляд наявних товарів

Додавання нового товару здійснюється через POST /items. У тілі запиту передається JSON з обов’язковими полями id, name, price та додатковими параметрами. Після валідації даних товар додається до каталогу.


<img width="899" height="651" alt="{60712550-9187-4694-A78E-0BA777ADCB67}" src="https://github.com/user-attachments/assets/9dd52d96-38cb-4f83-ab34-34b55534612c" />

Рисунок 3 - Редагування товару

Оновлення інформації про конкретний товар реалізовано через PUT /items/<id>. Підтримується часткове оновлення полів (наприклад, ціни або ваги). Також надана можливість видалення товару. Сервер повертає оновлений об’єкт товару. На рисунку 4 надано приклад видалення товару.
